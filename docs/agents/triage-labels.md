# Triage Labels

The canonical triage label vocabulary for this repository:

- `needs-triage`: Newly arrived issues or requests that need human or lead triage.
- `needs-info`: Requires more information from user/stakeholder before work can begin.
- `ready-for-agent`: Fully specified and unblocked; ready for automated agent implementation.
- `ready-for-human`: Requires manual human intervention, external credential access, or architectural sign-off.
- `wontfix`: Rejected or out of scope.
